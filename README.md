## What is BacktestPro?

BacktestPro lets users examine trading bot concepts against historical market conditions. Its HTML-based format provides a lightweight, browser-accessible way to inspect how a strategy could have performed before it is used in a live setting.

The platform is intended for traders, developers, and quant enthusiasts who need an organized process for comparing bot results, identifying weaknesses, and improving strategy ideas. Backtesting replaces speculation with simulated analysis based on historical inputs and outcomes.

## Running a Backtest

1. Open BacktestPro in a browser.
2. Load or connect the bot strategy you want to investigate.
3. Choose the historical data or market period for the run.
4. Start the backtest and examine its output.
5. Modify the strategy and run another test when necessary.

A normal testing cycle looks like this:

- create or define the bot strategy
- select the historical test window
- execute the simulation
- review the resulting performance
- make changes and test again
